## 变更内容

- 将知识库从单一 BM25 升级为混合检索 RAG：BM25 词法检索 + BGE 中文向量检索 + RRF 排名融合。
- 接入多数据源：GitHub Status 真实事故与用户上传的 PDF、Markdown、TXT 文档。
- 返回可核查的来源、链接和检索信号，保留受限会话记忆与安全边界。
- 将非专业界面文案改为简体中文，并统一放大正文、输入框、分析结果和工具执行记录字号。
- 在事故控制台增加用途说明与中文状态标签；原始事故标题和正文继续保留来源语言，避免篡改证据。
- 明确不把当前流程标记为 Agentic RAG；在只有两个只读数据源且缺少评测集时，增加自主循环会提高延迟、成本和不可控性。
