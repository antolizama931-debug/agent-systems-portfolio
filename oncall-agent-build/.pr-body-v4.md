## 变更内容

- 重构导航页首屏：桌面端标题固定为两行，移动端采用语义完整的三行断句。
- 将四项能力改为宽屏四列紧凑卡片，减少无效留白并统一信息层级。
- 为真实事故增加中文概述，同时保留可展开的英文原始信息。
- 将五个工具阶段改为等宽、对齐的执行流程。
- 将行动区实际高度从约 520px 降至 332px，并补充事故控制台和知识库 Agent 两个入口。
- 将事故控制台扩展到 1440px，侧栏增加中文标签，调整事故列表和右侧运行状态的列宽与字号。
- 移除无实际功能的搜索和通知按钮，避免误导用户。

## 原因

原页面存在标题断行失控、卡片内容密度过低、控制台在宽屏中过小、事故原文与中文说明层级不清等问题，影响阅读效率和操作理解。

## 验证

- `pytest -q`：21 项通过。
- `node --check frontend/app.js`：通过。
- 1600px 桌面端：主控制台宽 1440px，无横向溢出。
- 390px 移动端：导航页和控制台均无横向溢出。
- 浏览器控制台错误：0。
- 四张能力卡等高，五个工具阶段顶边完全对齐。
